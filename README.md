
# ☀️ Solar Energy Prediction Using Machine Learning

## 📌 Project Overview

Solar energy generation depends on several environmental and operating conditions such as solar irradiation, ambient temperature, module temperature, and time of day.

This project uses **Machine Learning regression techniques** to predict the **AC Power generated by a solar power plant** based on environmental and time-related features.

Two regression algorithms are implemented and compared:

- Linear Regression
- Random Forest Regression

The project also includes exploratory data analysis, feature importance analysis, time-based evaluation, prediction visualization, and a Streamlit web application for interactive predictions.

---

## 🎯 Objectives

The main objectives of this project are:

1. Analyze solar power generation data.
2. Preprocess and clean the dataset.
3. Perform Exploratory Data Analysis (EDA).
4. Identify important factors affecting AC power generation.
5. Build a Linear Regression model.
6. Build a Random Forest Regression model.
7. Compare the performance of both models.
8. Evaluate the models using a time-based train/test split.
9. Visualize actual and predicted AC power.
10. Save the trained Random Forest model.
11. Develop an interactive Streamlit application for making predictions.

---

## 📊 Problem Statement

The objective is to predict the **AC Power generated by a solar power plant** using environmental and time-related measurements.

### Input Features

The model uses the following features:

| Feature | Description |
|---|---|
| `AMBIENT_TEMPERATURE` | Temperature of the surrounding environment |
| `MODULE_TEMPERATURE` | Temperature of the solar panel/module |
| `IRRADIATION` | Solar irradiation received by the panel |
| `HOUR` | Hour of the day |
| `MINUTE` | Minute of the measurement |
| `DAY` | Day of the month |
| `MONTH` | Month of the measurement |

### Target

| Target | Description |
|---|---|
| `AC_POWER` | AC power generated by the solar plant |

Since `AC_POWER` is a continuous numerical value, this is a **regression problem**.
